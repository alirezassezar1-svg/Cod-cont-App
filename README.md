# Code Converter Pro — Static PWA + AI

نسخه‌ی استاتیک (GitHub Pages) با هوش مصنوعی Gemini داخل مرورگر.

- بدون کلید: موتور داخلی (Deterministic AST) کار می‌کند.
- با کلید: دکمه‌ی **AI: OFF** پایین‌سمت‌راست ← کلید Gemini را وارد کن (از aistudio.google.com/apikey). کلید فقط در localStorage مرورگر خودت می‌ماند و در ریپو نیست.

ساختار: فایل‌های ریشه = بیلد آماده‌ی سایت. پوشه‌ی `source/` = کد منبع (`npm install --legacy-peer-deps && npm run build`).
